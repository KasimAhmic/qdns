# qDNS

My attempt at making a high performance DNS server with adblocking capabilities

## Project Status

qDNS is still very much in development and has no functional components yet.

## Development

To get started, clone the repository and install the dependencies:

```bash
git clone https://github.com/KasimAhmic/qdns.git --recurse-submodules
cd qdns
cmake -S . -B build
cmake --build build
```

## Documentation

Documentation is available in the `docs` folder. You can generate the documentation using Doxygen:

```bash
cd qdns
doxygen
```
